# Lemrix TCG website brand basis

Updated 4 November 2026 (Australia/Brisbane).

## Source of truth

The user supplied the current Lemrix TCG logo and the Cook’d × Lemrix comic panel. The current business Instagram avatar matches the supplied logo. The collaboration picture contains mascots representing two different businesses: Lemrix and Cook’d. The user's correction establishes that distinction. Preserve both; do not replace the café character with another Lemrix-like character or invent character lore.

The site now uses the full-resolution original eight-panel announcement carousel, retrieved from the exact post supplied by the user. The hero uses panel 1; the collaboration reader contains all eight panels. The inaccurate generated extension was removed, is not packaged and is not a brand source. The cream logo and the blue mascot in the original comic are existing source artwork; the site does not invent a new identity to reconcile their colours.

## Brand decisions

| Element | Basis | Website treatment |
|---|---|---|
| Primary mark | User-supplied current logo; matches @lemrix.tcg | Original bitmap, proportional crop, no reconstructed wordmark |
| Primary navy | Dominant flat logo pixel RGB 28/40/98 | #1c2862 |
| Cream | Supplied logo lettering, approximate from raster | #f8e8c8; page paper #faf2df |
| Secondary colours | Original illustrated café panel | Muted slate, warm window gold; used sparingly |
| Collaboration | @lemrix.tcg links the actual @cookd.cafe carousel | Both original marks, named partner, original artwork, coming-soon status |
| Typography | Soft round display forms complement supplied logo | Caprasimo display; Ranade body, retained from Awwwards font research. Neither font replaces the original wordmark |
| Voice | Proposed website copy, not an established brand slogan | Plain card-hobby language; no fabricated testimonials, scale claims or opening details |
| Motion | Stars, page reveals, card and binder interactions | Small, contextual, reduced-motion support; no mascot redraws |
| Commerce | Real current eBay/Whatnot channels | Clear external purchase routes; historic products labelled archive |

The headline “One more pack?” is proposed site copy, not a verified existing Lemrix slogan. The rejected “great company” line is absent from the site and downloads.

## Final polish

Original stream photography appears as a small editorial selection, without legacy logo files. New cream/navy logos remain the only standalone business marks. Self-hosted Lenis 1.3.27, gentle parallax, native touch scrolling and a persistent motion toggle are shared across the home and shop pages. Shopify remains a disabled integration placeholder. See cookd-story-sources.json, editorial-sources.json and SHOPIFY-HANDOFF.md.

## Deeper blue — 5 November 2026

At the user’s request, the website navy is now #182359, a small darkening of #1c2862 with essentially the same hue. Cream, original photography, and the collaboration illustrations are unchanged. HTML theme colours, interface states, the Shopify placeholder, favicon and vector rewards use the updated navy. A scoped SVG colour filter maps the current logo bitmap’s navy background to the new web tone while preserving its cream lettering and original shapes; the source logo file remains unchanged.

## Mascot artwork — 10 November 2026

For new mascot scenes, export each character as a separate cutout with a transparent background. Match the full illustration’s lighting, colour, texture and proportions. The Lemrix Window uses the Midnight Service cutouts of Cook’d holding pancakes and Lemrix opening a foil pack.
